# UI Design System Template

Use this as `docs/ui/design-system.md` in an application project.

```markdown
# UI Design System

## Design Principles

- ...

## Color Roles

| Token | Purpose | Light | Dark |
|-------|---------|-------|------|
| primary | Primary actions | ... | ... |
| secondary | Secondary actions | ... | ... |
| success | Successful/available state | ... | ... |
| warning | Attention/reserved state | ... | ... |
| danger | Error/occupied/destructive state | ... | ... |
| surface | Cards and panels | ... | ... |
| background | Application background | ... | ... |
| text | Primary text | ... | ... |
| muted | Secondary text | ... | ... |
| border | Dividers and control borders | ... | ... |

## Typography

| Level | Use |
|-------|-----|
| Page title | ... |
| Section title | ... |
| Body | ... |
| Caption | ... |
| Table | ... |
| Button | ... |

## Spacing

Define the standard spacing scale and page padding.

## Shape and Elevation

Define border radius, card shape, dialogs, and elevation.

## Responsive Breakpoints

Define desktop, tablet, and mobile behavior.

## Standard Components

- App bar
- Side navigation
- Breadcrumb
- Tabs
- Search
- Data grid
- Form
- Card
- Button
- Badge/status
- Dialog
- Notification
- Empty state
- Loading state
- Error state

## Accessibility

Define keyboard, focus, labels, contrast, and icon-only control requirements.

## Domain Status Conventions

Define semantic state tokens for the application's domain. Do not let individual
screens invent their own meanings for the same status.
```
