# RestoPro — Vision

## Product

RestoPro is a restaurant management platform for Indian restaurants, cafés, QSRs, bakeries, and small restaurant chains.

## Vision

Give restaurant staff one reliable system for managing tables, orders, kitchen preparation, billing, payments, inventory, purchasing, customers, and reporting.

## First vertical slice

The first demonstrable journey is:

```text
Select table → Take order → Send KOT → Prepare → Ready → Serve → Bill → Pay → Close table
```

## Target users

- Owner
- Manager
- Cashier
- Captain / waiter
- Kitchen staff

## Product principles

- Fast at the POS
- Touch-friendly
- Clear operational status
- Real-time where useful
- GST-aware for India
- Multi-outlet ready
- AI-assisted but not AI-dependent

## UI direction

The application uses a consistent RestoPro shell: dark navigation, a compact top bar, a light content area, clear status badges, dense operational tables/grids, and touch-friendly action controls.

The exact visual language is defined separately in `ui/design-system.md`; individual screens are defined in `ui/` and validated through HTML mockups.
